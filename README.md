# 🎁 SecretDraw

Projeto desenvolvido para a disciplina de Programação para Internet (PPI).

Um sistema de Sorteador de Nomes e Amigo Secreto feito com HTML, CSS e JavaScript puro.

---

## 🚀 Funcionalidades

- Adicionar participantes
- Adicionar vários nomes separados por vírgula
- Remover participantes
- Sorteio simples aleatório
- Sistema de amigo secreto
- Revelar resultado individualmente
- Refazer sorteio
- Interface responsiva

---

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
